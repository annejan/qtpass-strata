QtPass: Twelve Years in Stone

Twelve Years in Stone: a git history as a canyon

DESCRIPTION
Twelve years of QtPass, the open-source GUI for pass, as a canyon wall.

Every layer of rock is one month of code. Left to right is time. A glowing front, "now", lays the rock down as it moves. Behind it, each layer is only as thick as the code from that month that still survives, so the old walls wear down as new work rewrites them.

Sparks are commits, coloured by author. Beacons are releases. The river of light is the translations, from 1 language to 64. The quiet years pass by night. Then 2026 erupts: 2,306 commits, 44% of all history, and 61% of the older code rewritten.

5,247 commits · 180 contributors · 64 languages · 72,701 lines of code, still cooling.

QtPass 2.0.0-rc3 came out today: https://github.com/IJHack/QtPass/releases/tag/v2.0.0-rc3
https://qtpass.org

Made from the real git history: git-of-theseus for the code survival data, Blender (EEVEE) for the canyon, a soundtrack generated from the commits themselves, ffmpeg for the finish. Low-resolution preview; a 4K version is coming.
